# Категории данных для хранения

Полный перечень того, что имеет смысл держать в личном хранилище.
Столбец «Тип» — как это ложится в текущую программу: `Логин`, `Заметка`,
`Карта`, `Счёт` или нужен новый шаблон.

## 1. Доступы к сайтам и приложениям

| Что | Примеры | Тип |
|---|---|---|
| Логины и пароли сайтов | магазины, форумы, сервисы, подписки | Логин |
| Почта | Яндекс, Gmail, Mail.ru, корпоративная | Логин |
| Госуслуги и госсайты | Госуслуги, nalog.ru, ГИБДД, суды | Логин |
| Банки и брокеры (вход) | интернет-банк, инвестиции | Логин |
| Passkeys | вместо пароля, когда появится поддержка | новый шаблон |
| Коды 2FA (TOTP) | секрет для генератора кодов | Поле «TOTP» |
| Резервные коды 2FA | 10 одноразовых кодов | Заметка (скрытая) |
| Ответы на секретные вопросы | девичья фамилия матери и т. п. | Поля записи |
| Пароли приложений | Gmail, Яндекс.Почта для почтовых клиентов | Логин |

## 2. Рабочие доступы

Хранить только если это не запрещено политикой работодателя.

- корпоративная почта, VPN, RDP, 1С, CRM, Jira/Confluence;
- Git (корпоративный), Slack/Teams, внутренние порталы;
- пропуска, коды от офисных дверей и переговорных.

## 3. Разработка, API и инфраструктура

| Что | Примеры |
|---|---|
| Токены Git | GitHub PAT, GitLab, Bitbucket |
| Ключи облаков | Yandex Cloud, AWS, Google Cloud, Azure |
| Платёжные API | ЮKassa, Stripe, Robokassa, Тинькофф |
| Мессенджеры и боты | Telegram bot token, VK app secret |
| AI-сервисы | OpenAI, Anthropic, DeepSeek, YandexGPT |
| Хостинг и домены | reg.ru, Cloudflare, DNS-провайдер |
| Базы данных | строки подключения, пароли Postgres/MySQL/Redis |
| CI/CD | GitLab runners, GitHub Actions secrets |
| SMS и рассылки | SMS.ru, SendGrid, Unisender |
| SSH-ключи | приватные ключи, парольные фразы |
| GPG/PGP | ключи и отзывные сертификаты |
| Прочие секреты | `.env`, webhook-секреты, JWT-ключи подписи |

Правило: для API-ключей хранить ещё и права доступа (scope) и срок действия,
чтобы понимать, что можно отозвать.

## 4. Финансы

- **Карты:** номер, срок, CVV, PIN, банк, платёжная система, лимиты.
- **Счета:** расчётный счёт, IBAN, SWIFT/BIC, банк.
- **Интернет-банк:** логин, кодовое слово, токены, PIN.
- **Брокерские счета:** логин, номер счёта, ИИС.
- **Электронные кошельки:** ЮMoney, PayPal, Ozon Карта.
- **Крипта:** seed-фразы (только офлайн, не в облаке), API-ключи бирж —
  с правами «только чтение/торговля», без вывода средств.
- **PIN и PUK** от карт и SIM.

## 5. Документы РФ

| Документ | Поля |
|---|---|
| Паспорт РФ | серия, номер, кем и когда выдан, код подразделения, прописка |
| Загранпаспорт | серия, номер, срок действия, орган выдачи |
| СНИЛС | номер |
| ИНН | номер, кем выдан |
| Полис ОМС | номер, страховая компания, срок |
| Водительское удостоверение | серия, номер, категории, дата выдачи, срок |
| Свидетельство о рождении | номер, дата, орган ЗАГС, родители |
| Свидетельство о браке / разводе | номер, дата, орган ЗАГС |
| Военный билет / приписное | серия, номер, военкомат, категория |
| ЭЦП | владелец, токен (Рутокен, JaCarta), PIN-код, срок |
| ОГРНИП / документы ИП | номер, дата регистрации, налоговая |
| Дипломы, аттестаты, сертификаты | номер, дата, учебное заведение |

Фотографии и сканы документов лучше держать не в менеджере паролей,
а в зашифрованном контейнере (VeraCrypt) или в защищённой папке — и отдельно
от паролей.

## 6. Семья и дети

- документы супруга/супруги, СНИЛС и полисы детей;
- свидетельства о рождении детей, прививочные сертификаты;
- школа/детский сад: личный кабинет, логин;
- доверенности, согласия на выезд ребёнка.

## 7. Медицина

- полис ОМС/ДМС, прикрепление к поликлинике;
- группа крови, резус-фактор, аллергии, хронические заболевания;
- принимаемые лекарства и дозировки;
- результаты анализов, рецепты, номера заказов;
- контакты врачей, стоматологии, страховой.

## 8. Недвижимость и ЖКХ

- кадастровый номер, выписка ЕГРН;
- договоры купли-продажи, аренды, ипотеки;
- лицевой счёт, управляющая компания, контакты аварийной службы;
- показания и номера счётчиков (не секрет, но удобно);
- коды от домофона, подъезда, кладовки.

## 9. Транспорт

- СТС, ПТС, VIN, номер двигателя;
- ОСАГО/КАСКО, техосмотр, диагностическая карта;
- личный кабинет ГИБДД, штрафы;
- парковочные пропуска, транспондер, каршеринг;
- логины приложений такси и каршеринга.

## 10. Страхование

- ОСАГО, КАСКО, ДМС, страхование жизни, имущества, путешественника;
- номер полиса, срок, страховая, телефон урегулирования убытков.

## 11. Туризм

- визы (шенген, США, Великобритания), сроки и номера;
- миграционные карты, бронирования отелей и авиабилетов;
- страховка путешественника;
- логины авиакомпаний, отелей, систем бронирования;
- номера программ лояльности (авиамили, отели).

## 12. Устройства, сети, доступ

- Wi-Fi: дом, дача, офис, гостевой;
- роутер и модем: админ-пароль, провайдер, тип подключения;
- NAS, домашний сервер, умный дом (камеры, замки, лампы);
- сигнализация, коды постановки/снятия;
- PIN и PUK SIM, IMEI телефонов, серийные номера;
- ключи восстановления BitLocker / FileVault, код блокировки устройства;
- коды сейфа, чемодана, велосипедного замка.

## 13. Лицензии, подписки, покупки

- Windows, Office, антивирус, Adobe, JetBrains, Steam;
- подписки: музыка, кино, доставка, облачные диски;
- чеки и гарантийные талоны (для техники — дата покупки и серийник).

## 14. Почта и мессенджеры

- основной и резервный email, коды восстановления;
- Telegram: пароль двухэтапной аутентификации, резервные коды;
- WhatsApp/Signal: PIN, коды резервной копии;
- социальные сети: VK, OK, Instagram, YouTube;
- коды восстановления аккаунтов Google/Apple/Яндекс.

## 15. Экстренная информация

- контакты близких и врача, «если со мной что-то случится»;
- инструкция для семьи: где лежит файл хранилища и резервная копия;
- как получить доступ к важным аккаунтам (без самого пароля в тексте);
- группа крови и аллергии — на случай потери сознания.

## Что не стоит хранить

- **Seed-фразы криптокошельков в облаке и в менеджере на телефоне** —
  только на бумаге или на аппаратном кошельке.
- **Корпоративные секреты**, если это запрещено политикой компании.
- **Чужие пароли** без согласия владельца.
- **Сканы документов** в папке, которая синхронизируется куда попало.
- **Мастер-пароль** рядом с файлом хранилища — где угодно.

## Что из этого уже поддерживается

Сейчас в «Хранителе» **18 типов записей**, у каждого — свои поля:

**Логин**, **Заметка**, **Карта**, **Счёт**, **Паспорт РФ**, **Загранпаспорт**,
**СНИЛС**, **ИНН**, **Водительское**, **Полис ОМС**, **ЭЦП**, **API-ключ**,
**Wi-Fi**, **PIN-код**, **Страховка**, **Недвижимость**, **Медицина**, **Автомобиль**.

Номера документов, CVV, PIN, IBAN и API-ключи помечены как скрытые: маскируются,
не участвуют в поиске и зануляются в памяти при закрытии записи.

Категории из списка выше, для которых пока нет отдельного шаблона (семья и дети,
туризм, подписки и лицензии, почта и мессенджеры), пока делаются через **Заметку**
или **Логин** с произвольными полями.
