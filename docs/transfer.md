# Перенос «Хранителя» на другой компьютер

Приложение портативное: отдельного установщика с мастером нет, но есть
`tools\install-hranitel.ps1` — он копирует программу, делает ярлык и по
желанию включает автозапуск.

## Что взять с собой

1. **Пакет** `Hranitel-<версия>-win64.zip` (или папку `dist\Hranitel-<версия>-win64`).
   Внутри уже есть всё: `vault-win.exe`, `vault-cli.exe`, `browser-host.exe`,
   папка `extension`, скрипты установки и документация.
2. **Файл хранилища** — ваш `vault.opvault` (например,
   `E:\Cloud\POSCloud\Хранилище\vault.opvault`). Это единственный файл с данными.
   Если он лежит в облачной папке, на новом ПК он может оказаться сам.

## Что НЕ переносить

- `vault.opvault.hello` — сайдкар Windows Hello. Он зашифрован ключом DPAPI
  **этого** компьютера и на другом не развернётся. Просто не копируйте его;
  на новом ПК включите Hello заново.
- Папки `target`, старые пакеты `dist` — это сборочный мусор.

## Что можно перенести по желанию

`%APPDATA%\Hranitel\` на новом ПК:

- `settings.txt` — тема, сочетания клавиш, путь к хранилищу, режим трея и
  автозапуска. После переноса поправьте строку `path=` под новый путь.
- `browser-sites.txt` — домены, которым разрешён доступ из браузера.
- `browser-host\ru.hranitel.bridge.json` переносить не нужно: установщик моста
  создаст его заново под новый путь и новый идентификатор расширения.

## Порядок на новом компьютере

1. Распакуйте zip, например в `C:\Users\<вы>\Downloads\Hranitel-0.12.0-win64`.
2. Установите приложение:

   ```powershell
   pwsh -File .\tools\install-hranitel.ps1
   # или с автозапуском и своим каталогом:
   pwsh -File .\tools\install-hranitel.ps1 -Dir 'D:\Apps\Hranitel' -Autostart
   ```

   Скрипт скопирует программу в `%LOCALAPPDATA%\Hranitel\app`, сделает ярлык
   «Хранитель» в меню «Пуск» и, если попросите, пропишет автозагрузку.
3. Запустите «Хранитель», укажите путь к перенесённому `vault.opvault`
   и откройте его мастер-паролем. Путь запомнится.
4. Расширение: `chrome://extensions` (для Яндекса — `browser://extensions`) →
   «Режим разработчика» → «Загрузить распакованное расширение» → папка
   `<куда установили>\extension`.
5. Мост к браузеру — скрипт сам найдёт идентификатор расширения в профиле:

   ```powershell
   pwsh -File "$env:LOCALAPPDATA\Hranitel\app\tools\install-browser-host-auto.ps1"
   ```

6. Перезапустите браузер и щёлкните иконку расширения: должно быть
   «Хранитель на связи (версия …)».

## Почему идентификатор расширения меняется

У распакованного расширения ID выводится из пути к папке. На новом ПК путь
другой — значит, ID другой, и мост надо зарегистрировать заново. Скрипт
`install-browser-host-auto.ps1` делает это сам: читает `Secure Preferences`
профиля, находит расширение по пути и прописывает ключ реестра.

## Windows Hello

На новом ПК вход по Hello надо включить заново: откройте хранилище паролем →
кнопка «Hello: выключен» → подтвердите. Старый сайдкар не подойдёт.

## Обновления

Приложение не обновляется само. Для новой версии распакуйте новый пакет и
повторите шаг 2 (старые файлы заменятся), либо просто замените `.exe` в
каталоге установки. Хранилище и настройки при этом не трогаются.
