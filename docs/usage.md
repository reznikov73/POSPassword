# Как пользоваться «Хранителем»

Пошагово, для обычной работы. Программа ничего не отправляет в интернет:
всё лежит в одном зашифрованном файле на вашем компьютере.

## Шаг 1. Запустить

Два способа:

- **Готовый файл:** `E:\Work\VSC\POSPassword\dist\Hranitel-<версия>-win64\vault-win.exe` — папка с самым свежим номером версии в `dist`.
- **Из VS Code:** нажмите `F5` (запуск с отладкой) или `Ctrl+Shift+B`, потом
  `target\debug\vault-win.exe`.

Откроется окно с двумя полями: «Файл хранилища» и «Мастер-пароль».

## Справка (F1)

В любой момент нажмите **F1** — откроется встроенная инструкция по всем функциям:
создание хранилища, записи и шаблоны, поиск, буфер обмена, импорт, Windows Hello,
резервные копии и что делать, если что-то не так. Повторный F1, Esc или крестик
закрывают окно.

Ту же справку можно открыть кнопкой **«Справка (F1)»** — на экране входа под кнопкой
темы и в правом верхнем углу основного окна. Справка не содержит секретов
и доступна до разблокировки.

## Шаг 2. Создать хранилище (один раз)

1. Нажмите **«Создать новый…»**.
2. Проверьте путь к файлу. По умолчанию:
   `C:\Users\<вы>\AppData\Roaming\Hranitel\vault.opvault`
   Можно указать свой, например `E:\Мои пароли\vault.opvault`.
3. Введите **мастер-пароль** — не короче 8 символов. Это единственный пароль,
   который нужно помнить.
4. Повторите его во втором поле.
5. Нажмите **«Создать хранилище»**.

Сразу запишите пароль в надёжном месте. **Восстановить его невозможно** — нет ни
подсказок, ни сброса, ни «вопроса о секрете». Забыли пароль — файл открыть нельзя.

Путь к последнему открытому (или созданному) файлу запоминается в
`%APPDATA%\Hranitel\settings.txt` — при следующем запуске поле «Файл хранилища»
уже заполнено, вводить его заново не нужно.

## Шаг 3. Добавить запись

1. Нажмите **«+»** рядом с полем поиска.
2. Выберите тип: **Логин**, **Заметка**, **Карта** или **Счёт**.
3. Заполните поля:
   - **Название** — обязательное, например «GitHub»;
   - **Логин** — почта или имя пользователя;
   - **Пароль** — введите свой, нажмите **«Случайный»** или **«Фраза»**
     (настройки — из окна «Генератор»), либо **«Вставить»** — взять пароль
     из буфера обмена. Под полем видна оценка: «≈ 96 бит · сильный»;
   - **Сайт** — адрес страницы входа;
   - **Ещё сайты** — дополнительные адреса того же сервиса, по одному
     в строке (например, кабинет `lk.domclick.ru` рядом с основным
     `domclick.ru`): поиск, быстрый доступ и расширение браузера
     понимают, что это один сервис;
   - **Заметки** — всё, что полезно помнить: код восстановления, ответы на
     секретные вопросы. Если оставить пустыми — в карточке появится кнопка
     **«Описать»**.
4. Нажмите **«Сохранить»**.

Запись сразу записывается в файл — отдельной кнопки «сохранить всё» нет.

### Быстрая вставка: логин и пароль одним движением

Когда логин и пароль уже есть текстом — в письме, в чате, в выгрузке браузера:

1. Скопируйте их в буфер: строку `mail.ru ivan Pa$$w0rd`, `ivan Pa$$w0rd`,
   `https://ivan:secret@mail.ru/` или строки «Логин: …» и «Пароль: …».
2. Нажмите **«Быстрая вставка»** в верхнем ряду кнопок.
3. Нажмите **«Взять из буфера обмена»** — программа разберёт текст сама
   (или вставьте вручную и нажмите **«Разобрать»**).
4. Проверьте поля — их можно поправить — и нажмите **«Создать запись»**.

Новая запись сразу получает осмысленное описание в заметках и выбирается в списке.

## Карты и счета

При выборе типа **Карта** появляются поля: владелец, номер карты, срок действия,
CVV, платёжная система, банк. У типа **Счёт** — банк, номер счёта, IBAN, SWIFT, валюта.

Номер карты, CVV, IBAN и номер счёта хранятся как скрытые поля:
- в списке они показываются точками, открываются кнопкой **«Показать»**;
- поиск по ним не работает — по выдаче нельзя подтвердить догадку о номере;
- копируются они так же, как пароль, с автоочисткой буфера.

Лишнее поле можно убрать крестиком, нужное — добавить кнопкой **«+ Добавить поле»**.
Так же переносятся произвольные поля из других менеджеров.

## Шаблоны документов и ключей

При создании записи нажмите **«+»** и выберите тип в списке «Тип» — поля появятся
готовыми, заполнять нужно только значения.

| Тип | Что спросит |
|---|---|
| Паспорт РФ | серия и номер, кем выдан, дата, код подразделения, прописка |
| Загранпаспорт | серия и номер, кем выдан, дата, срок действия |
| СНИЛС / ИНН | номер, налоговый орган, дата постановки на учёт |
| Водительское | серия и номер, категории, дата, срок |
| Полис ОМС | номер, страховая, срок |
| ЭЦП | владелец, носитель, PIN, удостоверяющий центр, срок |
| API-ключ | сервис, ключ, права доступа, срок |
| Wi-Fi | сеть, пароль, шифрование, где находится |
| PIN-код | назначение, PIN, PUK, примечание |
| Страховка | компания, номер полиса, вид, срок, телефон |
| Недвижимость | адрес, кадастровый номер, площадь, документ, собственник |
| Медицина | группа крови, аллергии, болезни, лекарства, поликлиника, врач |
| Автомобиль | марка, VIN, госномер, СТС, ПТС, ОСАГО, техосмотр |
| Карта / Счёт | реквизиты и PIN |

Номера документов, PIN, CVV, IBAN и ключи помечены как скрытые: показываются
точками, открываются кнопкой «Показать», не находятся поиском и затираются
в памяти при закрытии записи.

Любое поле можно переименовать, удалить крестиком или добавить своё
кнопкой **«+ Добавить поле»**.

## Импорт из Bitwarden, 1Password или Яндекс Браузера

1. В своём менеджере сделайте экспорт:
   - Bitwarden → «Инструменты» → «Экспорт хранилища» → `.json` (без пароля) или `.csv`;
   - 1Password → «Экспорт» → `.csv`;
   - Яндекс Браузер → настройки → «Пароли» → выгрузка в `.csv`
     (файл вида `yandex_browser_passwords_*.csv`).
2. В «Хранителе» нажмите **«Импорт…»** в правом верхнем углу.
3. Укажите файл: кнопкой **«Выбрать файл…»**, перетаскиванием в окно или
   кнопкой **«Вставить путь»** (если файл скопирован в Проводнике).
   Формат можно оставить «Определить автоматически».
   Если открыть окно случайно — **«Закрыть»** или Esc.
4. Нажмите **«Импортировать»**.

В ответе будет, сколько записей добавлено и сколько пропущено как дубликаты.
Совпадения по названию и логину (или номеру карты) не перезаписываются —
существующие записи остаются как есть.

В выгрузке Яндекса нет колонки с названием: «Хранитель» берёт имя сайта
из адреса (`https://mail.yandex.ru/...` → `mail.yandex.ru`), а если адреса
нет — логин. Комментарий становится заметкой, теги переносятся в метки.

Важно: файл экспорта содержит все пароли в открытом виде. После импорта удалите его.

## Шаг 4. Найти нужное

Поле **«Поиск»** слева ищет по названию, логину, сайту и заметкам.
По самому паролю поиск не работает — так сделано специально, чтобы по выдаче
нельзя было угадывать пароли. Пустой запрос показывает все записи.

Над списком — **категории** с количеством записей: Все, Логины, Карты, Счета,
Заметки, Документы, Ключи. Категория и поиск работают вместе.

## Шаг 5. Взять пароль

1. Выберите запись в списке слева.
2. Нажмите **«Копировать»** рядом с полем «Пароль».
3. Перейдите в нужное окно и вставьте: `Ctrl+V`.
4. Через **30 секунд** буфер обмена очистится сам — но только если там всё ещё
   лежит скопированный пароль.

Кнопки «Копировать» есть и у логина, и у сайта.

## Шаг 6. Посмотреть пароль глазами

Нажмите **«Показать»** — точки превратятся в текст. **«Скрыть»** вернёт обратно.
Полезно, когда пароль нужно ввести на другом устройстве вручную.

## Шаг 7. Изменить или удалить запись

- **Изменить:** выберите запись → **«Изменить»** → поправьте поля → **«Сохранить»**.
- **Удалить:** выберите запись → **«Удалить»** → подтвердите.
  Удаление необратимо: корзины нет.

## Шаг 8. Закрыть на время

- **«Заблокировать»** — окно вернётся к вводу пароля, ключ из памяти уничтожается.
- Или просто отойдите: через **5 минут** без мыши и клавиатуры программа
  заблокируется сама.

Для продолжения снова введите мастер-пароль.

## Вход через Windows Hello

1. Откройте хранилище мастер-паролем.
2. В правом верхнем углу нажмите **«Hello: выключен»** — кнопка станет
   «Hello: включён». Подтверждать ничего не нужно: ключ уже разблокирован.
3. Заблокируйте хранилище. На экране входа появится кнопка
   **«Войти через Windows Hello»**.
4. Нажмите её и подтвердите личность пальцем, лицом или PIN.

Что происходит внутри: ключ хранилища обёрнут отдельным ключом, а тот защищён
DPAPI — привязкой к вашей учётной записи Windows и этой машине. Файл хранилища
вместе с сайдкаром `*.hello`, украденные на другом компьютере, бесполезны.
Мастер-пароль остаётся запасным входом: если Hello не сработал (отказ, нет
устройства, чужая машина), введите его как обычно.

Выключить: та же кнопка **«Hello: включён»**. Сайдкар удаляется, вход — только
по мастер-паролю. Смена мастер-пароля тоже удаляет обёртку: включите Hello заново.

## Светлая и тёмная тема

Кнопка **«Тема: светлая»** (или «тёмная») есть на экране входа под полями и в правом
верхнем углу основного окна. Один клик — и оформление меняется целиком.

Выбор сохраняется в `%APPDATA%\Hranitel\settings.txt` и применяется при следующем
запуске. По умолчанию — светлая тема.

## Шаг 9. Закрыть совсем

Закройте окно обычным крестиком. Все изменения уже в файле, ничего теряться не должно.

## Где лежит файл и как сделать копию

Файл `vault.opvault` — это и есть всё хранилище: один файл, внутри зашифрованные
записи. Скопируйте его на флешку или внешний диск — это и будет резервная копия.
Восстановление: вернуть файл на место и открыть мастер-паролем.

Не кладите файл в общие папки и не отправляйте в мессенджерах. Если очень нужно
хранить копию в облаке — помните, что без мастер-пароля внутри ничего не прочитать,
но и сам пароль нельзя хранить рядом с файлом.

## Сменить мастер-пароль

Прямо в окне: кнопка **«Пароль»** в правом верхнем углу. Введите текущий пароль,
новый (не короче 8 символов) и повтор. После смены файл перешифровывается новым
ключом, старый пароль перестаёт работать, вход через Windows Hello отключается —
включите его заново.

Из командной строки то же самое:

```powershell
cd E:\Work\VSC\POSPassword
cargo run -p vault-cli -- passwd "E:\Мои пароли\vault.opvault"
```

## Автоввод в программы

1. Выберите нужную запись в «Хранителе» (окно можно свернуть). Категории и поиск
   над списком помогают быстро её найти.
2. Щёлкните в поле логина или пароля в другой программе.
3. Нажмите **Ctrl+Alt+P** (по умолчанию) — приложение напечатает логин, Tab, пароль и Enter.

Комбинацию можно сменить: **«Настройки»** → «Записать сочетание» → нажмите нужную
комбинацию целиком (например, `Ctrl+Shift+F2`) — диалог закроется сразу. Можно и
вписать сочетание текстом в поле и нажать «Сохранить». Если клавиши заняты другой
программой, останется прежняя комбинация, а в диалоге появится причина.

Одновременно может работать только одно окно «Хранителя»: второй запуск покажет
предупреждение и закроется. Если оставить старое окно открытым, горячая клавиша
будет работать из него, а новое — только сообщит, что клавиши заняты.

Если активно само окно «Хранителя», ввод не выполняется — так защищено от
случайной печати в свои поля. В окна, запущенные от администратора, Windows ввод
не пропускает: скопируйте пароль кнопкой «Копировать».

## Быстрый доступ (Ctrl+Shift+Space)

Палитра выбора записи поверх всех окон — не нужно искать «Хранитель» среди
окон и вспоминать, где он в списке:

1. Работаете в браузере или программе — нажмите **Ctrl+Shift+Space**.
2. «Хранитель» поднимется поверх окон с узкой палитрой. Сайт открытой страницы
   подставляется в поиск сам (адресная строка читается через UI Automation:
   Chrome, Edge, Яндекс Браузер), а курсор уже стоит на первой подходящей
   записи — можно сразу нажимать Enter. Если для сайта записи нет, в поиск
   попадает имя сайта: `fialkaspb.ru` → `fialkaspb`.
3. Можно печатать дальше — список фильтруется по названию, логину и сайту.
   Записи, подходящие окну, из которого пришёл вызов, стоят наверху с пометкой
   «сайт совпадает».
4. **Enter** — фокус вернётся в прежнее окно, и туда введутся логин и пароль.
   Порядок выбирается по курсору: в поле пароля — сначала пароль, затем
   Shift+Tab и логин; в обычном поле — логин, Tab, пароль. Если вернуть фокус
   не удалось, палитра скажет об этом и ничего не напечатает.
   **Ctrl+C** — скопировать пароль выбранной в палитре записи, **Esc** — закрыть.

Комбинация меняется там же, в «Настройках», второй строкой под автоводом.
Палитра работает только при открытом хранилище: если оно заблокировано,
программа поднимет окно, поставит курсор в поле пароля и откроет палитру сама
после входа.

## Трей и автозапуск

Без запущенного «Хранителя» не работают ни горячие клавиши, ни автозаполнение
в браузере — поэтому окно по умолчанию не закрывается, а сворачивается
в область уведомлений.

- Крестик в углу окна прячет программу в трей; закрыть совсем — «Выход» в меню
  значка.
- Меню значка: «Открыть», «Быстрый доступ», «Заблокировать», «Настройки»,
  «Выход». Щелчок по значку открывает окно.
- Галочка «Запускать при входе в Windows (свёрнутым в трей)» в «Настройках»
  прописывает автозагрузку (`HKCU\…\Run`, ключ `--tray`).
- Обе галочки можно снять: тогда закрытие окна завершает программу, как раньше.
- Хранилище всё равно блокируется через 5 минут бездействия — «в трее» не
  значит «разблокировано».

## Автозаполнение в браузере (Chrome/Edge/Яндекс)

Расширение подставляет пароли из «Хранителя» в формы входа и предлагает
сохранять новые. Пароли не хранятся в браузере: каждый запрос идёт в
приложение через локальный мост. Установка:

1. `cargo build --release -p browser-host` — собрать родной хост.
2. В браузере: `chrome://extensions` → «Режим разработчика» → «Загрузить
   распакованное расширение» → папка `extension`. Скопировать идентификатор.
3. `tools/install-browser-host.ps1 -ExePath .\target\release\browser-host.exe
   -ExtensionId <идентификатор>` — прописать манифест и реестр.
4. Запустить «Хранитель» и открыть хранилище.

Дальше: на странице входа щёлкните иконку замка в поле пароля — расширение
покажет записи этого сайта. Первый раз «Хранитель» спросит разрешение:
«на этот раз / всегда для домена / отклонить». Новый или изменённый пароль
при отправке формы входа приложение предложит сохранить — подтверждение
происходит в окне «Хранителя». В списке есть и «Сгенерировать пароль».

Подробности: [browser.md](browser.md).

## Избранное

Звезда в строке списка или в карточке добавляет запись в избранное; то же
есть в контекстном меню (правая кнопка мыши по строке). Чипс «★ Избранное»
над списком показывает только избранные записи — это же делает Ctrl+8.
Флаг хранится в файле хранилища и переживает перенос на другой компьютер.

## История пароля и возврат после удаления

Каждая смена пароля записи (в окне или через расширение браузера) уносит
прежний пароль в историю — до пяти последних версий. В карточке блок
«История пароля: N верс» раскрывается щелчком: дата смены, маска,
копирование прежнего пароля и кнопка «Сделать текущим».

Случайно удалили запись? 10 секунд внизу окна висит кнопка «Вернуть» —
запись восстановится с теми же названием, датами и полями. Блокировка
окна сбрасывает возврат.

## Резервные копии

При каждом сохранении прежняя версия файла копируется рядом как
`<имя>.bak` — всегда есть одно поколение назад. Откройте `.bak` как
обычное хранилище, если что-то пошло не так.

Копия с датой в имени (например, `vault-2026-11-18.opvault`) — меню ⚙ →
«Резервная копия…». Файл зашифрован мастер-паролем, его можно держать на
флешке или в облаке.

## Стойкость мастер-пароля и защита от перебора

При создании и смене мастер-пароля под полем — индикатор: примерная
энтропия в битах и вердикт. Предупреждение «входит в топ-10 000
употребимых» означает, что пароль стоит заменить.

Список «Защита от перебора» выбирает параметры Argon2id — Стандарт
(64 МиБ, 3 итерации), Усиленный (128 МиБ, 4) и Максимальный (256 МиБ,
4). Кнопка «Замерить» показывает время разблокировки на этом компьютере:
усиленные пресеты заметно медленнее на старых машинах. Параметры пишутся
в файл; повысить их можно при смене пароля, старые хранилища открываются
как раньше.

## Сроки и напоминания

Сразу после разблокировки, если у записей есть истекающие (30 дней и
меньше) или просроченные сроки, внизу окна появляется напоминание с
кнопкой «Аудит». В списке такие записи помечены бейджем: янтарный — срок
на исходе, красный — просрочено. Кнопка «Аудит · N» в тулбаре показывает
число находок: зелёная галочка — всё в порядке.

## Окно и журнал

Размер и позиция окна запоминаются между запусками; если монитор
отключили, окно вернётся на видимый экран. Журнал работы —
`%APPDATA%\Hranitel\log.txt` (ротация 1 МиБ, три файла). В журнале
только действия и коды процессов: названия записей и секреты туда не
попадают.

## Одноразовые коды (TOTP)

Если в записи есть скрытое поле **TOTP** (base32-секрет или ссылка `otpauth://`),
карточка показывает текущий код и сколько секунд осталось до его смены.
Кнопка **«Копировать»** рядом с кодом кладёт его в буфер — очистится через 30 секунд.

Секреты из импорта Bitwarden и 1Password уже на месте: после импорта коды работают
сразу. Поддерживаются SHA1, SHA256, SHA512, 6–8 цифр и нестандартный период.
Сам секрет на экран не выводится.

## Аудит хранилища и сроки

Кнопка **«Аудит»** в правом верхнем углу проверяет:

- повторяющиеся пароли — один пароль в нескольких записях;
- короткие пароли — меньше 12 символов;
- записи, которые не обновлялись больше года;
- истекающие и просроченные документы, карты, полисы — за 90 дней до срока.

Клик по находке открывает запись. Сроки видны и в самой карточке: рядом с полем
«Срок действия» появляется «осталось N дн.» или «просрочен на N дн.».
Всё считается на вашем компьютере, никуда не отправляется.

## Экспорт копии

Кнопка **«Экспорт…»** сохраняет копию хранилища:

- **JSON (полный)** — все типы записей, поля, теги; подходит для резервной копии;
- **CSV (Bitwarden)** — для переноса в другой менеджер паролей.

Нужно подтвердить мастер-пароль, потому что файл содержит все пароли в открытом
виде. После переноса удалите его; копию лучше хранить на отдельном носителе.

## Генератор паролей и запоминаемые фразы

Кнопка **«Генератор»** в верхнем ряду открывает окно с двумя режимами:

- **Случайные символы** — длина 8–64, классы символов, фильтр похожих `Il1O0o`;
- **Запоминаемая фраза** — слова через дефис и цифры, например
  `Корабль-Мандарин-Вишня-Сосна-42`. Такой пароль проще запомнить и набрать,
  а стойкость при достаточном числе слов та же. Русских слов в словаре больше
  1000 (10 бит на слово), есть и английский список — для сайтов, которые не
  принимают кириллицу.

Под образцом видно честное число — сколько бит энтропии при текущих настройках —
и вердикт: слабый (меньше 40 бит), средний (до 65), сильный (до 90) или очень
сильный. Настройки применяются и к кнопкам **«Случайный»**/**«Фраза»** в диалоге
записи. **«Копировать»** кладёт пароль в буфер — через 30 секунд он исчезнет.

## Осмысленные описания записей

Кнопка **«Описания»** показывает, у скольких записей пусты заметки, и составляет
для них человекочитаемые описания — для каждого типа записи свой шаблон:

- логин: «Логин на сайте mail.ru: ivan. Подключён одноразовый код (TOTP).
  Обновлено 12.05.2026.»;
- карта: «Карта банка …: номер •••• 1234, действует до 12/28.»;
- документ: «Паспорт РФ, выдан: … (12.05.2020). Серия и номер — в скрытом поле.».

Кнопка **«Добавить описания (N)»** заполняет заметки всем записям без них сразу;
записи с вашими заметками не трогаются. Описание видно в списке под названием,
участвует в поиске и правится кнопкой **«Изменить»**.

Секреты в описание не попадают: пароли, номера карт и документов и ключи
остаются в скрытых полях — в описании карты видны только последние 4 цифры.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| F1 или Ctrl+H | Открыть или закрыть справку |
| Ctrl+Alt+P | Автоввод в активное окно (сочетание записывается в «Настройках») |
| Ctrl+Shift+Space | Быстрый доступ: палитра записей поверх всех окон |
| Ctrl+F | Перейти в поле поиска |
| Ctrl+C | Скопировать пароль выбранной записи (когда курсор не в поле ввода) |
| Esc | Закрыть диалог или очистить поиск |
| Enter | В поле пароля — открыть хранилище |

## Командная строка (кратко)

```powershell
cargo run -p vault-cli -- list "путь\vault.opvault"        # список записей
cargo run -p vault-cli -- show "путь\vault.opvault" github  # одна запись
cargo run -p vault-cli -- gen --length 24                   # просто пароль
cargo run -p vault-cli -- gen --phrase --words 5 --lang ru  # запоминаемая фраза
```

Пароль в CLI показывается только с флагом `--reveal`.

## Если что-то не так

| Сообщение / ситуация | Что делать |
|---|---|
| «Неверный пароль или повреждённый файл» | Проверьте раскладку и CapsLock. Если пароль точно верный — файл повреждён, достаньте резервную копию. Программа намеренно не говорит, что именно случилось. |
| «Пароли не совпадают» | При создании хранилища оба поля должны совпадать. |
| «Мастер-пароль должен быть не короче 8 символов» | Придумайте пароль длиннее. |
| «Файл уже существует» | В этом пути уже есть хранилище. Выберите другой файл или откройте существующий кнопкой «Открыть». |
| Окно заблокировалось само | Так задумано: 5 минут бездействия. Введите пароль. |
| Пароль пропал из буфера обмена | Автоочистка через 30 секунд. Скопируйте снова. |
| Не помню, как работает функция | Нажмите F1 — откроется встроенная справка. |
| F1 ничего не открывает | Скорее всего, запущен старый exe из прежнего пакета в `dist`. Запустите самый свежий `dist\Hranitel-<версия>-win64\vault-win.exe`; запасной вариант — **Ctrl+H** или кнопка «Справка (F1)». |

## Три правила, которые важнее всего

1. **Мастер-пароль не восстанавливается.** Забыли — данные потеряны.
2. **Резервная копия файла — ваша страховка.** Делайте её после важных изменений.
3. **Программа не проходила внешний аудит.** Для личного пользования это нормально,
   но хранить в ней чужие секреты и раздавать её другим людям без проверки не стоит.
