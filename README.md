# Хранитель

Локальный менеджер паролей для Windows. Один зашифрованный файл, никакой сети и аккаунтов.
Ядро на Rust, интерфейс на egui, отдельный CLI для проверки и скриптов.

Проект лежит в `E:\Work\VSC\POSPassword`.

## Что умеет

- 18 типов записей с готовыми полями: логины, заметки, карты, счёта, паспорт РФ и загранпаспорт, СНИЛС, ИНН, водительское удостоверение, полис ОМС, ЭЦП, API-ключи, Wi-Fi, PIN-коды, страховки, недвижимость, медицина, автомобиль.
- Шифрует файл Argon2id (64 МиБ, 3 итерации) + XChaCha20-Poly1305.
- Открывается мастер-паролем; неверный пароль и повреждённый файл неотличимы по ответу.
- Вход через Windows Hello: палец, лицо или PIN вместо пароля; ключ хранилища обёрнут AES-256-GCM и защищён DPAPI, опцию можно выключить в любой момент.
- Импорт из Bitwarden (JSON, CSV), 1Password (CSV) и Яндекс Браузера (CSV); повторный импорт пропускает дубликаты.
- Поиск по названию, логину, сайту, заметкам и тегам. Пароли и номера карт в поиск не попадают.
- Генератор паролей: длина 8–64, классы символов, без визуально неоднозначных `Il1O0o`; окно «Генератор» показывает честную оценку энтропии и вердикт (слабый/средний/сильный).
- Запоминаемые пароли-фразы: «Корабль-Мандарин-Вишня-Сосна-42» — 3–8 слов из словаря (1000+ русских, есть английский для сайтов без кириллицы), 0–4 цифры, свой разделитель и заглавные.
- Быстрая вставка: скопированный «логин пароль», `login:password`, «сайт логин пароль», адрес вида `https://ivan:secret@site.ru` или строки «Логин: …»/«Пароль: …» разбираются в готовую запись — одним Ctrl+V из буфера.
- Осмысленные описания: кнопка «Описания» составляет для всех записей без заметок человекочитаемое описание («Логин на сайте mail.ru: ivan. Обновлено 12.05.2026.»); секреты в описание не попадают, описание видно в списке и участвует в поиске.
- Индикатор стойкости рядом с паролем: оценка в битах и цветной вердикт.
- Копирование в буфер обмена с автоочисткой через 30 секунд.
- Автоблокировка через 5 минут бездействия.
- Светлая и тёмная тема; выбор запоминается между запусками; путь к последнему хранилищу тоже запоминается.
- Смена мастер-пароля перевыводит ключ с новой солью.
- Встроенная справка: **F1** (запасной вариант — **Ctrl+H**) в любом месте окна открывает инструкцию по всем функциям и горячим клавишам; кнопка «Справка (F1)» — на экране входа и в основном окне.
- Одноразовые коды TOTP: карточка показывает текущий код и время до смены; понимает base32 и ссылки `otpauth://`, SHA1/SHA256/SHA512.
- Аудит хранилища: повторяющиеся и короткие пароли, давно не обновлённые записи, истекающие и просроченные документы, карты, полисы.
- Экспорт в JSON (полный) и CSV (раскладка Bitwarden) с подтверждением мастер-пароля.
- Смена мастер-пароля прямо в окне — файл перешифровывается, обёртка Hello сбрасывается.
- Горячие клавиши: F1/Ctrl+H — справка, Ctrl+F — поиск, Ctrl+C — пароль записи, Esc — закрыть диалог.
- Автоввод в программы: горячая клавиша (по умолчанию Ctrl+Alt+P, записывается нажатием в «Настройки») печатает логин, Tab, пароль и Enter в активное окно; работает, даже когда «Хранитель» свёрнут.
- Автозаполнение в браузере (Chrome/Edge, модель KeePassXC): расширение `extension` + родной хост `browser-host` + локальный канал. Иконка замка в полях входа, список записей по клику, сохранение новых и изменение паролей с подтверждением в «Хранителе», разрешение доступа по доменам, генератор паролей прямо на странице; пароли не хранятся в браузере. Установка — `tools/install-browser-host.ps1`, устройство — `docs/browser.md`.
- Несколько сайтов у записи: основной адрес и список «Ещё сайты» — сайт и его кабинеты (lk.domclick.ru и domclick.ru) живут в одной записи; матчинг идёт по базовому домену, фишинговые похожие адреса отсекаются.
- Быстрый доступ (как Quick Access у 1Password): Ctrl+Shift+Space из любого окна поднимает палитру выбора записи — фильтр, стрелки, Enter возвращает фокус прежнему окну и печатает туда логин и пароль; записи, подходящие окну по домену или имени сайта, поднимаются наверх.
- Категории над списком (Логины, Карты, Счета, Заметки, Документы, Ключи) с количеством записей и поиском внутри категории.
- Контрастная тема: почти чёрный текст, видимые рамки кнопок и полей.
- Номер версии виден в заголовке окна.

## Чего пока нет

- Синхронизации между устройствами и мобильного клиента (следующий этап).
- Автозаполнения в приложениях (не браузере) и passkeys.
- Иконки в трее и сворачивания в трей.
- Внешнего аудита. Для личного использования это нормально, для раздачи другим людям — нет.

## Сборка и запуск

```powershell
cargo build --release -p vault-win      # приложение
.\target\release\vault-win.exe

cargo build --release -p browser-host  # родной хост для расширения браузера

cargo test --workspace                  # 119 тестов: ядро, импорт, шаблоны, Hello, TOTP,
                                         # аудит, экспорт, фразы, разбор вставки, описания,
                                         # сайты и матчинг, рамка моста
```

Готовый пакет для запуска без сборки — папка `dist\Hranitel-<версия>-win64`
(самый свежий номер версии); рядом лежит `.zip` для переноса на другой компьютер.

Приложение создаёт хранилище по кнопке «Создать новый…». По умолчанию предлагается
`%APPDATA%\Hranitel\vault.opvault`; путь можно изменить в поле.

## Работа в VS Code

1. Откройте папку `E:\Work\VSC\POSPassword` (Файл → Открыть папку).
2. VS Code предложит установить расширения из `.vscode/extensions.json` — согласитесь.
3. Дальше — три кнопки:

| Действие | Как |
|---|---|
| Собрать проект | `Ctrl+Shift+B` |
| Запустить с отладчиком | `F5` |
| Выбрать любую задачу | `Ctrl+Shift+P` → «Задачи: Выполнить задачу» |

Задачи в списке названы по-русски: «Сборка (debug)», «Тесты», «Запуск приложения»,
«Всё перед коммитом» и другие. У каждой есть пояснение — оно видно при выборе.

Как пользоваться: [docs/usage.md](docs/usage.md).
Как работать над кодом: [docs/development.md](docs/development.md).

## CLI

```powershell
cargo run -p vault-cli -- init  .\vault.opvault
cargo run -p vault-cli -- add   .\vault.opvault --generate
cargo run -p vault-cli -- list  .\vault.opvault
cargo run -p vault-cli -- show  .\vault.opvault github --reveal
cargo run -p vault-cli -- gen   --length 24
cargo run -p vault-cli -- gen   --phrase --words 5 --lang ru
cargo run -p vault-cli -- passwd .\vault.opvault
cargo run -p vault-cli -- import .\vault.opvault .\bitwarden_export.json
```

Мастер-пароль запрашивается интерактивно. Для скриптов можно задать `VAULT_PASSWORD` —
не используйте её на общих машинах.


## Проверено

- `cargo test --workspace` — 119 тестов: round-trip, неверный пароль, порча шифротекста,
  подмена параметров KDF в заголовке, смена пароля, юникод в мастер-пароле, генератор,
  фразы (уникальность словарей, форма, энтропия), разбор вставленных логинов/паролей,
  описания записей (все 18 типов, без утечки секретов, раунд-трип через файл),
  нормализация и матчинг сайтов (поддомены, www, порты, двусоставные зоны, фишинг,
  заголовки окон, старые файлы без списка сайтов), протокол моста (разбор запросов,
  форма ответов без паролей), рамка Native Messaging (round-trip, обрывы, лимит размера),
  импорт Bitwarden/1Password/Яндекса, карты и счёта, маскировка секретных полей, шаблоны документов,
  обёртка Windows Hello (раунд-трип, чужой ключ, порча сайдкара, инвалидация при смене
  пароля), DPAPI-раундтрип, коды TOTP по векторам RFC 6238, разбор сроков и отчёт
  аудита, экспорт JSON/CSV с обратным импортом.
- Ручная проверка: создание хранилища, добавление записей, поиск, показ, отказ при неверном пароле.
- Интерфейс: экран входа и основной экран отрисовываются, кириллица читается.
- Вход через Windows Hello на машине с настроенным Hello проверяется по чек-листу
  `docs/handoff.md`, раздел 5: включение, блокировка, вход без пароля, откат на пароль.
- Автоввод Ctrl+Alt+P проверен на живом окне (тестовое поле): логин, Tab, пароль
  с кириллицей и Enter доходят без потерь; проверка — по п. 20 того же чек-листа.
