# Окно-мишень для проверки автоввода

Маленькая программа без сети и без доступа к хранилищу: окно с полями
«Логин» и «Пароль» и кнопкой «Войти». Нужна, чтобы проверить Ctrl+Alt+A:
«Хранитель» печатает в активное окно логин, Tab, пароль и Enter,
а эта программа показывает, что именно попало в поля.

## Как проверить

1. Запустите `login-probe.exe`.
2. Откройте хранилище в «Хранителе» — первая запись выберется сама
   (в правом нижнем углу будет «Автоввод: <название>»).
3. Щёлкните в поле «Логин» в окне проверки.
4. Нажмите **Ctrl+Alt+A**.
5. В окне появится строка «Что пришло в поля»: логин и пароль
   (точками; «Показать» раскрывает пароль). Если в пароле есть кириллица
   или другие не-ASCII символы, программа об этом сообщит.

То же самое можно сделать кнопкой «Ввести в окно» в карточке записи:
нажмите её и успейте переключиться в окно проверки (отсчёт 3 секунды).

Программа ничего не сохраняет и никуда не отправляет.
